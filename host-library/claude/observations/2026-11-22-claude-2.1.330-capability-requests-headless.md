Run **2026-11-22**, Windows, Claude Code **2.1.330**, on the logged-in subscription. Two headless invocations (`claude -p`) were made by an AI session; no human typed. The lead was the research orchestrator (`--agent orchestrator-research`), Sonnet (`claude-sonnet-5-5`), `--effort medium`, `--permission-mode auto`, `--output-format json`, the agent-teams variable unset, no user and no answer to a prompt. Run 2 added `--continue` and ran in the same folder.

The folder (`<workspace>/run-1`, a fresh `git init`) held the `deep-research` Bundle installed natively for the Claude host (`agents-united add deep-research -t claude --native -y --copy`) from the build of branch commit `b0624b48` (ADR 0076, the requests block). The requests block of `orchestrator-research`, `socratic-mentor` and `deep-research` equals the repository file's block byte for byte; the rest of each installed file differs only by what the install writes. `design/proposal.md` proposed keeping user sessions in a module-level `Map` in a Node.js service that runs as four replicas behind a load balancer.

Prompt 2 gave three answers "in the order the mentor asked" and asked for the next round. The session records are the evidence (`~/.claude/projects/<folder>/`, main file and `subagents/`); line numbers below are 1-based record lines of those files. Not committed: the raw records, the folder, the prompts.
