# Capability requests through the lead: one headless loop on the real host

Run **2026-11-22**, Windows, Claude Code **2.1.330**, on the logged-in subscription. Two headless invocations (`claude -p`) were made by an AI session. No human took part. The second prompt supplied scripted answers. The lead was the research orchestrator (`--agent orchestrator-research`). It ran on `sonnet` (`claude-sonnet-5-5`) at medium effort (`--effort medium`) in permission mode `auto` (`--permission-mode auto`), while its definition names `opus` and `acceptEdits`; the other flags were `--output-format json` and the agent-teams variable unset. Run 2 added `--continue` and ran in the same folder.

The folder (`<workspace>/run-1`, a fresh `git init`) held the `deep-research` Bundle installed natively for the Claude host (`agents-united add deep-research -t claude --native -y --copy`) from the build of branch commit `b0624b48` (ADR 0076, the requests block). The requests block of `orchestrator-research`, `socratic-mentor` and `deep-research` equals the repository file's block byte for byte; the rest of each installed file differs only by what the install writes. `design/proposal.md` proposed keeping user sessions in a module-level `Map` in a Node.js service that runs as four replicas behind a load balancer.

Prompt 1 asked for two things and waived the grilling and the planning consultation: (1) the Socratic mentor challenges the design turn by turn, its questions come to the user and the answers go back to it; (2) the deep-research specialist says whether the installed Node.js supports `node:sqlite`, resting on the installed version. Prompt 2 gave three answers "in the order the mentor asked" and asked for the next round. The session records are the evidence (`~/.claude/projects/<folder>/`, main file and `subagents/`); line numbers below are 1-based record lines of those files. Not committed: the raw records, the folder, the prompts.
