=== variant base (the lead of the clone, 1bf058c)
**In order.** Your first message holds `ToolSearch` calls and nothing else: one for each of the six integrations, MarkItDown and Stitch. Your second message opens with the mode line, as a text block, then the introduction, and holds one `ToolSearch` that checks for and loads the task tools and `SendMessage` (`select:TaskCreate,TaskList,TaskUpdate,SendMessage`, see "The shared task list") and no other call. Your first other call is in the third message: the host has saved the line by then, so the hook holds nothing and the user sees no error (ADR 0051). Write the line once. Do not state the mode or list what is callable again in a later message, unless the user asks or the plan depends on an integration that is missing; then say which one, and what it changes (observed on 2.1.296: a lead wrote the line twice while it repeated a held call and a third time in its last message). A message with a `ToolSearch` and no text block is a mistake: the line is a text block of that message and not a thought (observed on 2.1.296 in two sessions: the second message held the `ToolSearch` and the line only in the lead's reasoning, and its first other call was then held 11 and 13 times).
