## Evidence tooling

The first collector read an earlier "I'll send the final report" line instead of the report, counted "ignore the earlier shutdown request" as a plain-text request, and called the foreground launch form "other". The fixes are tested (five of the 20 offline checks were red on the first version) and the first results are kept beside the corrected ones. The observer writes a session binding only when the transcript folder already exists at `SessionStart`. In a fresh project it does not, so the CLI session has none, and the Desktop session got one only at its resumed `SessionStart`; the exact id was supplied.

## Verdict and limits

Every pass line of H12a and H12b holds, and the natural late-notice path, listed as unverified in ADR 0055, was observed once. That verifies the intended behaviour once on each surface. It is not a reliability claim: one session per surface, two workers, one scenario, no control run of the previous text in this scenario (the 2026-10-15 run is an uncontrolled baseline with different prompts).

**Not established:** a failed or declined shutdown request; the nine-specialist team flow; a Desktop run in which `SubagentHandback` is provided and used under the new wording; process exit, cost and quota (the `SessionEnd` events are session events, not exits); other platforms and host builds.
