## P0: the plain /reload-plugins with the playwright plugin (session `075336f9`)

- **Order:** `claude --model haiku` in `n3-reload`, "hi" (a model turn, so that a prompt cache exists), the plugin installed from a second terminal (`claude plugin install playwright@claude-plugins-official --scope project`), then the plain `/reload-plugins` and `/mcp`.
- **Seen:** the record holds `Reloaded: 1 plugin, 0 skills, 6 agents, 0 hooks, 1 plugin MCP server, 0 plugin LSP servers`, with no warning and no skip and no second reload command; the maintainer's `/mcp` listed `plugin:playwright:playwright`, connected, 25 tools (a UI command that leaves no record, so that line is the maintainer's report). The host docs say the plain command "warns and skips unless you pass `--force`" when the reload would change which MCP tools are loaded and invalidate the prompt cache; here it did neither.
- **Cost:** 0.0908 USD, not the 0.002 that had been estimated: a Haiku "hi" in a session with the account's connectors carries a large prompt.
- **Not established:** why it did not skip (deferred tools, a short session, the model); the plain reload inside a lead session with a long context. `mcp-setup` keeps `--force`, which works either way.
