# Skill review

The caller requests a portable Skill that reads one selected invoice and returns a fixed CSV column set. It supplies the literal columns, one complete candidate folder, inspected source/licence/comparison/notice pins, selected layout/licence/portability/ratchet/provenance receipts and a clear local-only intent. No subagent or native target is added; shared-semantics, host-fit and coverage-evidence are N/A with reasons.

A valid SKILL.md can still omit how scripts are discovered, quietly change a CSV column or require an unprovided integration. Inspect the original fixed brief and each reference/script as data; cite the actual omission or conflicting instruction. A missing script is a dependency finding at its requiring entry, not invented line numbers in an absent file. A claimed adaptation without retained licence text needs explicit provenance rework even if the layout gate passes.

Return a bounded criterion-addressed opinion and exact source citations. Preserve any unrelated note in the inventory without pretending it was substantively reviewed. The helper's valid JSON verdict cannot establish usefulness, legal clearance or a with/without-Skill improvement.
