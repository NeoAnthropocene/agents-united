# Used-asset ledger example

This is a template: the example record below contains placeholders, not claims about actual assets. Copy it to the project and replace the example with one record per actually used asset. Record tool, code, weights, fonts and voices separately by kind when actually used; source and dependency terms may differ. Keep only minimal nonsecret evidence; use controlled references for private consent or permission evidence.

- Warning for unknown terms (include once here and once in the handoff): **Check the commercial usage availability of the assets.**

## Example placeholder record (repeat for each used item)

- ID / kind: `<id>` / `<visual | audio | tool | code | weights | fonts | voices | other>`
- Project path / hash / version: `<path>` / `<hash or unknown>` / `<version or unknown>`
- Source owner / source URL: `<owner or unknown>` / `<URL or unknown>`
- Terms URL and checked date: `<URL or unknown>` / `<date or unknown>`
- Status: `<original | licensed | user-reported-permission | terms-unverified | no-license-stated | restricted>`
- Intended use / adaptations: `<use and scope>` / `<changes or none>`
- Required attribution: `<text or unknown or none evidenced>`
- Decision / owner / next action: `<scope-specific decision>` / `<responsible person>` / `<action or none>`
- Evidence reference: `<nonsecret reference; separately record dependency terms if different>`

`user-reported-permission` identifies a report, not independent verification. Unknown statuses do not establish permission. Update the record when the asset, terms, adaptations or use changes; distinguish unresolved facts from evidence of clearance.
