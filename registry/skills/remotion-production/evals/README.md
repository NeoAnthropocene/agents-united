# Maintainer-only evaluation preparation

These fixtures are prepared, not executed model/host evaluations. Two production/repair
briefs have paired with-Skill/without-Skill conditions; the third is an unrelated control.
Keep model/settings, tools, context, approved inputs and disposable source baseline equal
within each pair. Record order and retain raw outputs, diffs, actual commands/exits and
artifacts. Judge decision handling and evidence, not a model's success account.

Preparing these cases does not authorize a paid host session or provider call. Follow the
separate host authorization/records protocol if a later pilot is approved. No numerical
improvement, threshold, creative quality or behavior claim is inferred from these prompts,
static gates or the existing B2/C1 runtime proof. `evals/` is excluded from resource packing
and every installed Skill lane under the repository's maintainer-only exclusion policy.
