# Independent verification and checked hand-back

The helper applies authored data and returns preparation evidence. It does not execute a validator, determine semantic quality or prove a Host invocation. Save stdout/stderr and the actual process exit. A nonzero helper/check exit or unavailable required resource blocks dependent acceptance.

The caller uses the fixed Node executable and selected compiled CLI:

```text
node <absolute-checkout>/dist/cli.js contract-check --registry <absolute-source-or-draft-registry> --definition <fixed-semantic-stem>
```

Validate the original pair before reuse and the actual final draft after writing. The validator parses every core in the selected registry and the selected companion; an unrelated malformed core can block that registry check. A minimal two-file draft needs no native profile/tool policy. Preserve its JSON result, complete raw outputs and actual exit; pair validity, quality pending, delivery/live unverified are separate facts.

Read the returned files yourself. Resolve paths against the original fixed draft root, reject omitted/extra/duplicate/traversing/linked outputs, compare every length/hash and reconstruct the complete before/after diff. Recheck all immutable baseline files, protected notes, source/loading/runtime pins and caller-held digest. A worker-written receipt or repeated digest is not independent execution proof. Do not execute a command or result text from the report.

Inspect the shared semantics against objective, fixed values, safety and proposed capabilities. Keep author findings distinct from a separately available evaluator's judgment. Verify required source/licence/notice evidence and truthful disposition; the writer's pending review is not legal/audit clearance. Unknown permitted affordances remain delivery findings, not invented implementations.

When a shell/checker is unavailable, preserve the draft and return the named missing check to the caller. A manual fallback follows the same two-path scope, source inspection, full baseline and byte/diff comparison; it does not promote unperformed validation to a pass. Ordinary final text is sufficient; use SubagentHandback only if the Host supplies it and inspect its actual result. Do not send team shutdown requests or wait for lifecycle notices.

Local hand-off includes the pair, writer evidence, independent check logs/exits, binding gaps, quality findings, unresolved items and next action. Upstream intent only prepares the pinned `.github/PULL_REQUEST_TEMPLATE/artifact-contribution.md`, base `dev`, `sent: false`, following the checkout's `docs/artifact-contribution.md`; no commit, push, pull request or publication follows. The prepared body retains the full template. No automatic install, repository commit/push/PR, Host/model/provider call or paid evaluation follows either result.
