# Meta Ad Creative Testing Playbook

## Overview & Purpose
`meta-ad-creative-testing` guides performance marketers through structured creative testing frameworks on Facebook & Instagram Ads to discover breakout creative winners.

## Core Directives & Standards
1. **Dynamic Creative Testing (DCT)** — Test 3 creatives, 2 primary texts, and 2 headlines per sandbox ad set with broad audience targeting.
2. **3-Second Hook Retention** — Analyze hook rate (3s video views ÷ impressions) and hold rate (15s views ÷ 3s views) to optimize video beginnings.
3. **Scaling Protocols** — Move winning creative combinations (CPA below target for 3+ consecutive days) to CBO scaling campaigns.
4. **Fatigue Monitoring** — Refresh visual assets when frequency exceeds 2.5 on prospecting campaigns or CPA spikes > 25%.

## Verification Checklist
- [ ] Meta Conversions API (CAPI) and Pixel events configured with Event Quality Match > 8.0.
- [ ] Clear naming conventions tagging creative concept, angle, format, and date.
