# Checks and availability

Use the selected checkout's built `dist/cli.js factory-check --registry <absolute-source-registry> --definition <stem> --host claude` on inputs. For output add `--artifact <absolute-native-file>`. The loading context defaults to subagent; use `--loading main` only when the fixed task calls for it. `--required-skills <JSON-array>` names task-required preloads; permitted identifiers in the four-field contract are not automatically required preloads. A missing build, runtime, source pair or required dependency blocks the dependent check.

This adapter reads actual core/contract, allowed native keys, required name/description, floor, class-derived tools, preloads and effective baseline guard registration/script. It also applies the repository's rules for a native role: the model posture of the role kind, the Session task tracking section when the core tracks tasks, the tools line exactly as the generator writes it (class tools sorted, then the canonical agent's server tools in its order), the canonical agent's guardrails and numbered directives in the core, and invariant coverage. The coverage file is JSON `{"version":1,"role":"<name>","definition":"<stem>","invariants":[...]}` with one entry for every core invariant: `{"invariant":"<exact text>","evidence":"<a sentence of the agent, verbatim>"}` or `{"invariant":"<exact text>","delta":{"disposition":"mapped|approximated|degraded|unsupported","rationale":"<why>"}}`. It reports deterministic findings with quality pending and live unverified. It does not author a contract, execute a model, evaluate prose, validate arbitrary other artifact types, or prove that the host loaded a file. Use actual selected guide/profile/tool policy; do not copy foreign-host tokens.

The bounded worker itself loads `realize-artifact` as a required preload, with an existing destructive guard. It has no delegation, messaging, web, provider, task lifecycle or publication grant. Its tools include editors/shells so this is not filesystem isolation. Missing guard files must be found before dispatch; existing host observations include a missing-script fail-open limit. Trusted project hook execution and actual spawned-worker enforcement still need separately authorized host proof.

Review artifact-specific quality, useful trigger/description, minimal support, native affordances, declared deltas and citations separately. Report quality findings even when deterministic validation passes. The evaluator and host-update worker are separate pending deliveries. LSP/MCP/Workflow are unused optional affordances here, not required delivery edges. An unavailable required edge cannot be made optional to pass.

For repaired files, read final bytes after the last edit and rerun any invalidated check. A receipt for a prior hash/revision is stale. Capture raw stdout/stderr, started/ended times, exact allowlisted argv/cwd, actual exit and classification. No pipe's exit or model-authored success summary substitutes for the process exit. Caller re-executes trusted checks independently; worker-written logs alone cannot establish that execution happened.
