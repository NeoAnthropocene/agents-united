# Checked return to the caller

Return an absolute result path plus job id/digest and complete final inventory: contained relative source paths, kind file, byte counts and SHA-256. Include every draft file, including untouched notes, and the complete actual before/after text for changed files. Postflight reconstructs this against the pinned immutable baseline, rejects undeclared creates/updates/deletes, omitted/extra/duplicate/traversing/linked files and stale preserved/input pins. The schema is strict; use null for absent before/after and absent local upstream preparation.

Cover each pinned input with its exact cited sections and explain its use. Declare native deltas as mapped/approximated/degraded/unsupported with rationale. Record original/inspired/adapted disposition truthfully with inspected evidence. Adapted material still needs actual pinned licence, attribution and notices under the supplied attribution rule; presence checks do not decide legal or semantic correctness. Block unresolved reuse rather than assigning original provenance to copied work.

Each check receipt names job digest, allowlisted id/executable/argv/cwd, actual timestamps, exit/classification, and absolute bounded stdout/stderr paths with byte counts/hashes under evidence. A required missing/skipped/unavailable/failed check cannot support draft status. Blocked/partial records carry open items; valid honest reports do not become completed work. The helper returns `acceptedDraft: false` even for a consistent draft report: caller-held job comparison, independent execution and quality review remain required. Worker quality findings remain visible separately from deterministic findings; live status stays unverified.

Local intent ends in a source draft and hand-off. Upstream intent retains the entire pinned `.github/PULL_REQUEST_TEMPLATE/artifact-contribution.md` in a prepared body, base dev, sent false. Preparing it authorizes no branch change, commit, push, PR or merge. The caller checks the final diff and staged diff before any later separately authorized commit, and all PR states before any authorized push.

The caller reads actual returned files and complete logs, compares paths/hashes/digest, then runs the pinned validator on final bytes. It sends evaluator work only after that evaluator's own delivery review; absent evaluator means quality pending. A model's self-report cannot establish host loading, guard execution, paid evaluation or behavioral improvement. No host/model/provider session is allowed by this job.
