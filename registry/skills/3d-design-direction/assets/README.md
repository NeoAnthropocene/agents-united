# Original 3D fixture templates

These are the records of the original procedural bottle technical fixture, not
preapproved user content. Generate the GLB with the installed
`threejs-scene-production/examples/create-bottle.mjs` helper. Adapt the scene,
source paths, request ID and budgets before production. Recompute every source,
evidence and derived-output SHA-256; example hashes do not clear a new asset.

`3d.example.json` shows the exact version 1 project schema. All declared sources,
including authored scene/code files and dependency textures, need corresponding
provenance records. `approvedUses` records the named reviewer's actual decision;
it is not inferred from a hash or licence label. Unreviewed personal-private
prototype assets can remain `unverified`, with `non-license` entries and a
maintainer-check warning in the Markdown ledger.

Public delivery requires usage-scoped reviewer approval and supported terms.
The initial commercial identifiers are MIT, Apache-2.0, BSD-2-Clause,
BSD-3-Clause, CC0-1.0, CC-BY-4.0 and LicenseRef-Project-Permission. The latter
requires real project-specific permission evidence. Noncommercial public work
also supports CC-BY-NC-4.0, CC-BY-NC-SA-4.0 and CC-BY-NC-ND-4.0 with their
applicable obligations and reviewer approval; ND adaptations remain blocked.
Unknown terms require resolution before public delivery. Known prohibited use
cannot be approved by merely choosing a private project.

The timeline is a structural test fixture. Reuse the installed
`audiovisual-review` validator and fingerprint; no separate 3D timing authority
is introduced. Capture receipt, current Khronos validation, viewer resources,
source files and PNG frames must match before a Shot Handoff is current. Human
visual acceptance and final sound sync remain separate, unverified checks.
