# Source audio ledger template

Complete one row/record per source/take. This is production prose, not a canonical manifest schema. Keep secrets and private consent documents out; cite controlled evidence locations. For a wordless cue, mark speech, script/transcript, captions, pronunciation and voice-consent fields not applicable with a reason; no invented narration or Kaan approval. Included speech requires Kaan-approved exact words and voice consent. All source-rights fields still require review.

- Project / sonic brief / exact approved script revision:
- Saved audio route / approved provider-model or local tool / Chris decision:
- Source ID / kind / scratch or final / selection status:
- Original project-relative file / SHA-256 / received or recorded date:
- Actual codec / rate / channels / decoded duration and evidence:
- Recording take details, supplied origin, synthesis spec/seed, or model/runtime/version/parameter record:
- External request/job identity and reconciled state, if applicable:
- Rights/consent reference / allowed placement/use / unresolved question owner:
- Edited file / SHA-256 / source trim / fades/crossfades / automation history:
- Approved text / pronunciation decisions / actual phrase marks:
- Timeline revision / canonical fingerprint / cue ID and frame range:
- Listening reviewer / devices / timecoded findings / selected or rejected reason:
- Finishing hand-off / required pickup or timing decision / approval date:

Report metadata checks, actual decoding, rights review and listening separately. Write **unverified** for checks without evidence. A model/provider prompt and successful output path do not establish source permission, pronunciation or final quality.
