# Worked example: acknowledged Kie narration to local finishing

This is an original offline-shaped example, not a completed performance or permission to spend. Chris has approved hybrid audio for a native 12-second film, exact words **“Your next step, clearly.”**, a commercially permitted stock voice selected by the human, a USD5 project ceiling and a USD1 acknowledged job ceiling. No voice clone or uploaded reference is needed. The sample voice/model IDs come from Kie's official model documentation retrieved 2026-10-24; actual availability, rights/plan, price, returned encoding and speaking performance are **unverified**. Read [provider cards](../../mcp-setup/references/media-providers.md) and confirm these before execution. The example dollar amounts are consent limits, not a price quote or vendor billing cap.

1. Resolve the installed siblings `mcp-setup` and `audiovisual-review`. On Claude, starting from this Skill root, `${CLAUDE_SKILL_DIR}/../mcp-setup/scripts/media-api.mjs` is the helper. Other Hosts obtain absolute installed roots; do not resolve from the working directory. The helper imports installed `audiovisual-review/scripts/review.mjs`. If either is absent, Chris resolves the installation before a job.
2. Review/copy [full selected preferences](../../mcp-setup/examples/kie-audio-project.json) into `<absolute-project>/media/project.json`, [approved job shape](../../mcp-setup/examples/kie-audio-job.json) into `media/narration-job.json`, and [status identity](../../mcp-setup/examples/kie-audio-status.json) into `media/narration-status.json`. Merge the actual project's output settings and decisions; never overwrite approved preferences silently. `approved: true` represents the already obtained per-job acknowledgment; remove it while approval is pending. Provider/model/modality/route must match exactly. The selected model's documented `input.text`/`voice`/parameters matter; no invented generic payload and no callback.
3. Run setup, then the human enters `KIE_API_KEY` privately in this project's `.env`. The agent never reads it. Setup preserves existing private content and creates safe placeholders/ignore rules only. OAuth for another service cannot authorize this Kie job.

```text
node "${CLAUDE_SKILL_DIR}/../mcp-setup/scripts/media-api.mjs" --project "<absolute-project>" --mode setup --provider kie
node "${CLAUDE_SKILL_DIR}/../mcp-setup/scripts/media-api.mjs" --project "<absolute-project>" --mode create --job media/narration-job.json
node "${CLAUDE_SKILL_DIR}/../mcp-setup/scripts/media-api.mjs" --project "<absolute-project>" --mode status --job media/narration-status.json
```

Run create once after acknowledgment. It reserves USD1 locally, submits once, persists the task and observes once. Invoke status deliberately later when queued/running; it never creates or implicitly polls. If submission times out without an ID, reconcile in Kie privately before any new job; the reservation remains. A successful create exit or task ID is not audio. Require `status: completed` and a real `media/assets/narration-r1.mp3` with MIME/byte count/SHA in `artifacts`. If Kie's returned encoding differs, `download-failed` retains identity: resolve the documented format/export through Chris without another paid submission. The helper does not guess a new output extension or publish a signed URL.

4. Preserve that original/hash and fill the [source ledger](../assets/source-ledger.md): provider Kie, underlying ElevenLabs model, public voice ID, exact text, requested parameters, task ID, human approval/rights evidence references, output metadata and actual billing reconciliation. Do not copy private keys, full responses, transient signed URLs or private consent documents into the ledger.
5. Inspect/decode and **listen** to actual audio. Mark exact word coverage, pronunciation, performance/artifacts, duration and phrase starts/ends. A numerical file check does not establish intelligibility. If it misses the approved copy or timeline, return the concrete mismatch to Chris/Motion; keep rejected original takes and request acknowledgment for any new generation.
6. Give `audio-post-production` the selected original, source-preserving edit plan, exact transcript/captions, phrase/cue marks, provenance and frozen timeline revision/fingerprint. Decode/resample to stereo48k as an edit under finishing while retaining the MP3. Use the sibling [finishing runbook](../../audio-post-production/SKILL.md) and its actual mix specification for new-revision WAV master/stems and measured/listening/mux review. Generated narration is a source, not the final mix or a timing freeze.

Anti-patterns: claiming the Kie key authenticates ElevenLabs MCP, treating USD1 as the vendor's cost cap, copying the sample as permission, resubmitting a timeout, passing only a task ID/URL to Sound, or claiming listening from the response metadata. All live provider, installed sibling/Host execution and listening results are **unverified** in this example.
