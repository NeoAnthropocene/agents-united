# Messaging Framework

In-house adaptation, credited to
[ui-skills.com/skills/nextlevelbuilder/brand](https://www.ui-skills.com/skills/nextlevelbuilder/brand)
(MIT source: `github.com/nextlevelbuilder/ui-ux-pro-max-skill`).

## Core layers
1. **Positioning statement** — one sentence: for [audience], [product] is the [category] that
   [key benefit], because [reason to believe].
2. **Value pillars** — 3–4 named pillars, each with a one-line proof point. Every campaign claim
   should trace back to one of these; if it doesn't, that's a signal the pillar list is stale or the
   claim is unsupported.
3. **Elevator pitch** — 2–3 sentences, no jargon, usable verbatim in a cold email or landing hero.
4. **Proof points** — specific, checkable facts (metrics, customer names with permission, awards).
   Never let generated copy invent a proof point that isn't listed here (this overlaps directly with
   `ux-writing`'s "never invent features/data" rule — treat both as the same constraint).

## Boundary vs. `copywriting-frameworks`
`copywriting-frameworks` supplies the persuasion structures (AIDA, PAS, before/after/bridge, etc.)
used to *write* a piece of copy. This messaging framework supplies the *facts and pillars* that any
persuasion structure must stay true to. Use both together: pull the approved claims from here, then
shape them with a framework from `copywriting-frameworks`.
