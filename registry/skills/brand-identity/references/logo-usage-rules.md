# Logo Usage Rules

In-house adaptation, credited to
[ui-skills.com/skills/nextlevelbuilder/brand](https://www.ui-skills.com/skills/nextlevelbuilder/brand)
(MIT source: `github.com/nextlevelbuilder/ui-ux-pro-max-skill`).

## Checklist before placing a logo in any artifact
- [ ] Using an approved lockup (primary / horizontal / stacked / icon-only) for the available space
      and aspect ratio — never stretch or recompose the mark by hand.
- [ ] Minimum clear space respected (commonly: the height of the mark's own icon element on all
      sides — confirm the brand's actual rule in `docs/brand-guidelines.md`, never assume a default).
- [ ] Minimum size respected (commonly 24–32px height for digital, larger for print — confirm per
      brand).
- [ ] Correct color variant for the background (full-color on light, reversed/white on dark or
      photographic backgrounds) — never place a low-contrast variant on a clashing background.
- [ ] Vector source (`.svg`/`.ai`/`.fig`) used for anything that will be scaled or printed; raster
      only for fixed-size digital placements.
- [ ] Not placed inside a busy area of a photo/illustration where it would lose legibility.

## What this skill will not do
It will not auto-generate a new logo mark. Logo *creation* belongs to a design/branding engagement
(e.g. `workflow-agency-brand-design-system`); this skill only governs correct *usage* of an existing,
approved mark.
