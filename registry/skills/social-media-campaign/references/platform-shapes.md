# Platform-native shapes

The same news is a different piece on each platform. Write the claim first, then the shape that platform's readers expect. A thread, a post and a video of the same news are three pieces, each making its claim in its own form.

| Platform kind | The shape |
|---|---|
| X | Short and concrete: the claim first, then the proof |
| A professional network | Enough context for someone outside the niche, and no fake lesson |
| A community forum | An honest question or a post-mortem, written as a member, with no sales language |
| Video | The result shown in the first seconds, with the visual sequence scripted |

Check each platform's current format before writing: a platform changes its format, and a deprecated one is not worth investing in. Sizes per platform go to Jamileh in the visual brief.
