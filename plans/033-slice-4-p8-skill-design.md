## P8b stage 1 — accepted 2026-11-13

Promoted from the 2026-11-13 proposal after the maintainer chose "Two stages (Recommended)" and "Approve as proposed (Recommended)". **Route.** The maintainer types `/author-skill <absolute task path>`. The coordinator holds no Skill tool and no grant changes. The coordinator writes a task record, checks it before the run, imports what the fork wrote, and checks it after.

**Checker interface.** `node check-skill-return.mjs --job <absolute skill-task.json> [--result <absolute skill-return.json>]` or `--help` alone. `--job` alone is preflight; `--job` with `--result` is postflight and skips the state-dependent preflight checks (create needs an absent draft root, repair needs the live draft to equal the baseline, the draft parent must hold nothing else), so a separate preflight must have passed before the fork ran. The task must be `<evidence>/skill-task.json` and the return `<producer>/skill-return.json`. Exit 0 prints one JSON line on stdout; any failure prints one JSON line on stderr with exit 1 (`status` `failed` or `unavailable`, `phase`, `code`, `reason`, `path`), first failure only. Every output carries `quality: pending`, `executionProof: unverified`, `live: unverified` and `acceptedDraft: false`. The only subprocess is a fixed `git rev-parse --verify HEAD`; nothing from the task or return is run.

**Codes (24, read from the script).** `USAGE`, `JOB_INVALID`, `ROOT_CONFLICT`, `BASELINE_MISMATCH`, `TEMPLATE_INVALID`, `CLOSURE_MISSING`, `LOADER_MECHANISM`, `RUNTIME_MISMATCH`, `CHECKOUT_HEAD`, `LIMIT`, `RESULT_PATH`, `RESULT_INVALID`, `DIGEST_MISMATCH`, `HELPER_RECORD`, `DRAFT_JOB_MISMATCH`, `SCOPE_VIOLATION`, `PRESERVATION`, `BYTES_MISMATCH`, `INVENTORY_MISMATCH`, `DIFF_MISMATCH`, `PROVENANCE_MISMATCH`, `EXTERNAL_ACTION`, `BLOCKED_STATE`, `STALE_INPUT`.

**Task fields (all required).** `version` 1, `kind` `skill-task`, `id`, `revision` (`r0` or `r1`), `previous` (null for `r0`), `operation` (`create` or `repair`), `intent` (`local` or `upstream`), `authoringHost`, `target` (null), `objective`, `fixedValues`, `constraints`, `acceptance`, `roots` (draft, producer, evidence, managed, protected), `source` (checkout, head, registry), `roles`, `baseline` (empty for a create), `draftJobTemplate`, `contributionTemplate`, `installed` (the eight `author-skill` files), `runtime`, `budget`. **Return fields (all required; every one a claim).** `version` 1, `kind` `skill-return`, `taskId`, `taskDigest`, `status` (`draft` or `blocked`), `helper` (draft job, stdout and stderr pins, `exitCode`, `runs`), `inventory`, `changed`, `report` (a pin or null), `claimedChecks`, `openItems`, `unverified`, `externalActions` (always empty).
