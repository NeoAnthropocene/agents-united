## Findings for the Claude-first pilot

- [Task tool availability](../../host-library/claude/pages/tools/tools-reference.md#task-tool-availability) documents the four Task tools or `TodoWrite` when `CLAUDE_CODE_ENABLE_TASKS=0`. Model defaults apply in Claude Code 2.1.268+, and the [SDK page](../../host-library/claude/pages/orchestration/agent-sdk-todo-tracking.md#model-availability) says TypeScript SDK 0.3.268 bundles that CLI. Opt-in is via `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`, named allow rules or an explicit tools list. Session start method, model and environment matter; a prose instruction does not enable a missing tool.
- The [subagent catalog](../../host-library/claude/pages/agent/sub-agents.md#available-tools) distinguishes ordinary background subagents from teammates: the ordinary background allowlist includes `TodoWrite` but omits the four Task tools; teammates additionally retain Task and Cron tools when the session provides them. Split-pane teammates are separate processes; they inherit `--tools` and deny rules but not `--allowedTools`, and a shell-exported todo flag is not passed through. In-process teammates follow the session's availability. An earlier draft called this a documentation conflict; the adjacent teammate exception resolves that interpretation. Runtime access remains unverified.
- SDK todo changes are assistant `tool_use` calls; create IDs come from correlated `tool_result` records. SDK task notifications instead cover background commands and subagents. `TaskOutput` was removed in v2.1.277 and was not the shared task-list API. The existing engineering orchestrator asks for `TodoWrite`; the digital agency already conditionally uses Task tools and has a fallback. Assess those independently before changing roles.
- Documentation changes also cover subagent frontmatter (`autoCompactWindow` from 2.1.296 and invocation effort from 2.1.292), hooks, permissions, skills, plugin components, MCP/desktop, workflow and teams. New and changed material needs a complete semantic comparison with every guide, `registry/hosts/claude/profile.json`, tool policy, native artifacts, translation ledger and `docs/host-primitive-matrix.md`; refreshed snapshot hashes alone do not certify compatibility.
