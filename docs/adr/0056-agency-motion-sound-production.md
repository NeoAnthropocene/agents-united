# ADR 0056: Agency motion and sound share approved timing and separate production routes

## Status

Accepted, 2026-10-25, for the maintainer-approved Plan 037 scope. This records placement and authored contracts; it does not declare live Motion/Sound behavior or the full installed lifecycle verified.

## Context

Agency briefs can include films, loops, explainers, soundtracks or standalone audio. The existing brand, copy, campaign, frontend, QA and compliance owners need a bounded way to propose media and preserve exact inputs through production. A renderer alone does not supply sonic direction, source rights, aligned final audio or acceptance evidence. A static brief must still remain static when media is declined or deferred.

Local prior art inspected includes `registry/bundles.json`, current agency/core/native role contracts, the agency full-campaign/ad-sprint/SEO playbooks, the shared media validator and project helper, `docs/skill-intake.md`, ADRs 0025, 0040, 0054 and 0055, and Plan 037's saved technical evidence. Native Skill anatomy follows [the reviewed Claude guide](../../host-library/claude/guide/skill.md), particularly its snapshot-backed [support-file anatomy](../../host-library/claude/pages/skill/skills.md#add-supporting-files), [substitutions](../../host-library/claude/pages/skill/skills.md#available-string-substitutions) and [subagent loading](../../host-library/claude/pages/agent/sub-agents.md#preload-skills-into-subagents). No claim of missing vendor behavior is made here.

The usual intake default places vendor/niche Skills in addons. The approved agency scope instead needs the complete direction-to-review capability available for consultation, while actual runtime installations and external services remain optional. Existing bounded planning and host lifecycle evidence must survive that placement.

## Decision

1. Add Motion Designer and Sound Designer as agency specialists. Declare all nine original agents-united/MIT Skills in `digital-agency` and the explicit end-user `full` inventory: `motion-design-direction`, `native-motion-production`, `remotion-production`, `video-generation`, `sound-design-direction`, `audio-generation`, `audio-post-production`, `audiovisual-review` and `workflow-agency-motion-production`. This is the approved placement exception to the addon default, not a general expansion of every Bundle. Original work carries truthful author/version/licence metadata and no invented upstream source or adaptation pin. Consulted motion ideas retain their actual source ledger and README credit.
2. Every relevant agency specialist identifies required or optional Media Requests during existing consultation. Chris consolidates questions and include/defer/decline within the existing planning/peer limits. Eleven specialist types are available choices; no all-role launch follows. Included motion proceeds through accepted brief/assets, storyboard/scratch audio, timing approval, parallel animation/audio, final Sound handoff, integration/render and distinct creative/technical/provenance review. Static, deferred and declined requests start no media production, runtime install or provider setup.
3. Native HTML/SVG/canvas is the recommended direct motion route. Remotion React production is an independently usable alternative, not an intermediate dependency. Scope runtime dependencies to the selected media project; keep them out of product/root dependencies. Audio independently chooses supplied/recorded sources, local synthesis, optional local models or an approved API/hybrid route. External footage generation is a separate opt-in. Local synthesis proves technical signals, not general speech/music capability. Provider/account/tool availability, licences, consent, setup and each paid job need actual evidence and authorization.
4. Persist complete nonsecret project preferences for renderer, audio route, footage opt-in, selected provider/model/modality/route, output and per-job USD ceiling. Preserve existing records. Defaults are 1920×1080 at 60 fps, H264/AAC, stereo48k, -16 LUFS +/-1 and true peak <=-1 dBTP. Saved choices and ceilings are not permission to upload or spend. A Sound-only WAV/sonic-logo Media Request uses renderer null; schema-required video preferences stay unused defaults and require neither Motion, a renderer install nor MP4 production. Sound obtains its own applicable cue/timing approval and delivers through audio/provenance review directly to Chris.
5. Both renderers and audio finishing consume the shared strict frame/cue schema. Its ranges are half-open integer frames; the canonical fingerprint includes revision, fps, canvas, scene/cue identities and bounds, and speech text. Changed timing/copy invalidates dependent handoffs even when a revision label is reused. The Final Sound Handoff carries the current fingerprint, stereo48k WAV master, aligned full-duration pre-master stems, cues/manifest, applicable transcript/captions, provenance and measurement/listening evidence. Stems retain gains and zero alignment; nonlinear mastering need not equal their sum.
6. Preserve ownership: Brand/Creative supplies approved visual assets, Copy owns exact words, Motion owns storyboard/animation/coordinated timing/integration, Sound owns sonic direction/sources/final audio, QA checks technical/playback/accessibility evidence, Compliance reviews claims/consent/rights and Chris resolves decisions. Sound owns Lead-approved timing/cue records for standalone audio when the shared schema is needed. Apply checks only to included assets; do not fabricate video, speech or a mux for standalone sound.
7. Keep Skills compact with progressive resources and explicit installed-root script paths. Shared helpers require sibling `audiovisual-review` resources in their source-relative layout; exclude maintainer `evals/` from installation. Nonagency frontend audits consult the capability only when installed and relevant, retaining their own Lead. A conditional mention does not install agency media or require it for ordinary engineering work.
8. Separate structural/file-presence checks, reported numbers, actual decoded master/mux measurements, complete visual/listening/sync review and rights approval. Mark required missing checks **unverified**; mark irrelevant ones not applicable with a reason. Static conformance, own-resource copying and bounded synthetic render/audio proofs establish only their measured scope. They do not prove installed lifecycle behavior, live Host loading/adherence, provider auth/billing, creative quality or rights.

## Consequences

Agency planning can discover media without changing the existing accepted brand/copy boundaries or launching every specialist. Native and Remotion remain independently selectable, and Sound-only delivery stays useful without video dependencies. Bundles carry more authored resources, while optional runtimes, local models and providers retain explicit project scope and authorization.

Shared timing and fingerprints make stale audio detectable, at the cost of reissuing affected handoffs after an approved timing/copy change. Resource layout must remain intact through installation, and standalone/shared-helper entry points need explicit compatibility checks. The pending standalone API-helper import and 59 fps sample-rounding boundary are J8 follow-ups, not fixes or proof supplied by this ADR.

Offline authoring and resource checks can close J7's bounded role/Skill criteria. Full build/typecheck/test, installed sibling/lifecycle matrices and Sound-only role consistency checks remain J8 work; actual Motion/Sound Host behavior and any behavioral eval stay **unverified** until a separately evidenced run. Existing launch, hand-back, delivery and shutdown semantics remain governed by the established host contracts.
