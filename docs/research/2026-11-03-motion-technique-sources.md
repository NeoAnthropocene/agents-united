## Selection and original authorship

Prior art search covered `src/`, `docs/adr/`, `plans/`, `registry/translation-ledger.json`, `tests/`, Claude guide/observations and `registry/skills/motion-design-direction` for `technique`, the four repository names and their slugs. Existing ten recipes, especially blueprint 8's technique matrix, already cover original treatments and both renderer mappings. The new resource extends that Skill rather than adding a framework. GitHub all-state PR search `repo:NeoAnthropocene/agents-united is:pr motion technique` returned zero results. Local `gh` could not read its sandboxed configuration; the connector supplied the search.

Eight compact cards cover acting, held drawing texture, layered paper, contour morphing, line reveals, type hierarchy, sourced map builds and controlled material reveals. Each supplies parameters, composition, an original reusable prompt, Native and Remotion implementation direction, Sound intentions and rejection checks. They use existing techniques and repository contracts. The candidate design differs from upstream scene prompts: no source story, copy, character, timing sequence, helper implementation, model recommendation or scoring rubric is transferred. Technical principles were rewritten for our canonical timeline, separated Motion/Sound ownership and existing proof gates. Inspection of the listed source files informed this comparison; no low-overlap score is offered as proof of originality.

## Verification boundary

The selector is read-only and offline. A returned card is an original prompt overlay, not an approved storyboard or complete prompt spec. It must feed `signatureShot`, `visualSystem`, `shots`, `depthLayers`, `beatGrid` and `proofPlan` in the existing spec; it cannot satisfy `referenceFrames`, `materialPasses` or `proofComparison` by itself. Real reference-view records, rights checks, bounded reproof, final-mux measurement and human acceptance remain required. The Remotion upstream redistribution hold in Plan 041 / ADR 0059 remains in effect.

Machine tests can verify selection and gate preservation. Rendered implementation, Native/Remotion visual parity, host invocation, playback, listening and creative acceptance are **unverified**. No real host/model session or paid generation was started.
